# Contributing

Keep changes to the ESRA specification reviewable, evidence-backed, and
runtime-neutral.

1. Update the technical specification and Loop Execution Protocol together
   when a change affects both architecture and execution semantics.
2. Separate normative requirements from implementation examples.
3. Document compatibility or migration impact for contract changes.
4. Keep platform-specific behavior in implementation repositories.
